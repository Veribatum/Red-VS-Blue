# Season 1 coverage

This release follows the **original 2003 episode order**, not the later streaming compilation numbering. All 19 episode slots are present. This table describes the implemented adaptation, not a promise that every line, gag, camera shot, PSA or bonus video has been reproduced. Dialogue is condensed and paraphrased. The UI labels it adapted dialogue; it does not present these lines as original episode scripts.

## Expansion scope

The intended long-term project can follow the complete series. **Only Season 1 is implemented now.** No later-season placeholder missions pretend to be playable. Season 2 should receive its own chronology review, character-state definitions, level layouts, artwork and tests before being added. Bonus PSAs and trailers are not part of this initial story campaign.

## Dialogue correction pass

The previous implementation substituted unrelated jokes for the original conversations. The correction restores the opening existential misunderstanding, the sniper-scope exchange, the vehicle naming discussion, the bogus supply errand, the fictional General, the reinforcement call before Tex’s arrival, and the O’Malley reveal. Lopez now appears from episode 2. All chapter dialogue was revised around the original scene subjects. These are short adapted exchanges, not a complete transcript or a shot-for-shot recreation.
