# Red // Blue: Canyon Chronicles

An unofficial **2D side-scrolling fan adventure** based on the first season of Red vs. Blue. This is the new GitHub version; it does not replace the earlier 3D Sites prototype.

## Included in this build

- All 19 original Season 1 episode slots, in order, with **56 playable objectives**.
- Playable Grif, Simmons, Donut, Caboose, Sarge, Tucker, Tex, and ghost Church at appropriate story points.
- Original vector character sprite sheets: 12 poses/frames each for ten character/color variants, plus canyon and vehicle art.
- Walking, jumping, crouching, shooting, grenade physics, reloads, Warthog driving, Sheila target practice, flag pickups, escort/escape routes, ghost possession, CPR and repairs.
- Conversations, captions, character gestures, scripted story events and chapter reports.
- Keyboard/mouse, touch buttons with drag-to-aim firing, and gamepad input.
- Checkpoints and completed chapters saved locally in your browser. All chapters are available from the menu.
- Original procedural music and sound effects. Optional browser computer voices are off by default.

**Status:** playable first implementation, not a finished recreation of the complete show. Later seasons, proper voice performances, bespoke illustrated cutscenes and a complete line-by-line adaptation are not included. Each Season 1 episode is represented, but dialogue is original and scenes are adapted into gameplay. See [story coverage](docs/STORY-COVERAGE.md) and [verification](docs/VERIFICATION.md) for exactly what exists and what remains unverified.

## Play locally

From this folder:

```sh
python3 -m http.server 8080
```

Open **http://localhost:8080**. Alternatively, with Node installed, `npm start` runs the same server. Use HTTP rather than opening index.html directly: browsers restrict module imports from file URLs. There are no third-party packages, CDNs or external runtime requests.

## Controls

| Action | Keyboard / mouse | Touch | Gamepad |
| --- | --- | --- | --- |
| Move / drive | A / D, left / right | Left / right arrows | Left stick |
| Jump | Space, W, up | Up button | A |
| Aim / fire | Mouse + click; X fires current aim | Hold FIRE, drag to aim | Right stick / RT |
| Talk / take / possess / CPR | E | USE | X |
| Assist repairs | Hold E | Hold USE | Hold X |
| Grenade | G | G | RB |
| Crouch | S / down | Down button | B |
| Reload | R | Automatic when empty | Y |
| Sprint | Shift | — | — |
| Pause | Esc | PAUSE | Start |

Grenades replenish after a short cooldown. You can retry an objective after dying. In the final throw, the displayed arc shows the grenade path; a miss does not consume your only chance.

## GitHub Pages

The repository includes a Pages deployment workflow. In **Settings → Pages → Build and deployment**, set **Source: GitHub Actions**, then run the **Deploy game** workflow. The workflow tests the game and uploads only `index.html`, `style.css`, `src/` and `assets/`.

The code does not assume Pages is already enabled. CI runs independently on pushes and pull requests.

## Development

```sh
npm test
npm run check
npm run assets
```

`src/model.js` contains the simulation and state transitions without browser APIs. `src/render.js` draws the world and sprite animations. `src/game.js` owns input and UI. `src/campaign.js` holds the chapter data. Original SVG assets are generated by `scripts/build-assets.mjs`; the campaign converter uses the earlier original fan dialogue in `scripts/previous-campaign.mjs` and adds connecting scenes.
